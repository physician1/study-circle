# Study Circle — static website assignment

## Open the site
Extract the ZIP first, then open index.html in a web browser. Keep all files in the same folder. No installation or internet connection is required.

## Requirement map
| Assignment requirement | Implementation |
| --- | --- |
| At least four pages | index.html, about.html, sessions.html, join.html |
| Semantic HTML5 | HTML5 doctype; header, nav, main, section, article, aside, footer |
| External stylesheet | styles.css on every page |
| Responsive layout | Flexbox, Grid, fluid headings, 700px media query |
| Table | sessions.html: caption, thead, tbody, scoped headings |
| Form | join.html: labels, text, email, select, textarea, checkbox |
| JavaScript validation | script.js: submit handler, field checks, inline errors, focus |
| Proposal | PROPOSAL.md |

## How validation works
The submit event runs JavaScript checks. Invalid data produces field-specific errors and focuses the first invalid field. Valid data produces a success message. Both paths prevent navigation because this is a static demonstration without a backend. No entries are transmitted or saved. If your instructor requires actual delivery of form data, ask which receiving endpoint to use.

## Before submitting
- Add your student/course details to PROPOSAL.md and review the wording.
- Read the HTML, CSS, and JavaScript so you can explain them.
- Follow your course’s rules about outside assistance.
- Check every navigation link and test at desktop and phone widths.
- Submit an empty form; try a one-character name, malformed email, no session, a short or whitespace-only goal, and an unchecked agreement.
- Correct every field and confirm the success message.
- Use only the keyboard to navigate and complete the form.
- Upload each HTML file to https://validator.w3.org/nu/ for independent standards validation.

The club and schedule are fictional. The proposal is separate from the four website pages.
